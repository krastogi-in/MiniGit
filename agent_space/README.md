# Agent space

Ticket scratch for the AI SDLC loop. Write run artifacts **only** under `agent_space/<ISSUE-KEY>/` — never under product `docs/` or repo-root `tasks/`.

| Phase output | Path |
|--------------|------|
| Idea | `agent_space/<KEY>/ideas/` |
| Spec | `agent_space/<KEY>/specs/` |
| Plan / todo | `agent_space/<KEY>/tasks/` |
| Review notes | `agent_space/<KEY>/reviews/` |

Product code/tests stay in `src/` / `tests/`. People guides stay in `docs/ai-sdlc/`.
