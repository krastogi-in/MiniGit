# Agent Space

Per-ticket run artifacts live here. Each issue key gets its own folder.

```
agent_space/
  <ISSUE-KEY>/
    ideas/       # idea-refine one-pagers
    specs/       # spec-driven-development specs
    tasks/       # planning-and-task-breakdown plan + todo
    reviews/     # code-review-and-quality findings
```

**Not product docs.** Product documentation belongs in `docs/`. Product code
belongs in `src/` and `tests/`. This directory is for the AI SDLC loop's
working artifacts only.

Skills write here via `sdlc-loop`. The human reviews artifacts on the outer
loop (HUMAN GATE, VERDICT). See `Skills/REGISTRY.md`.
